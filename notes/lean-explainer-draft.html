Reading the s(n) Lean statements

A Lean proof is only as good as its statement. The kernel checks that the proof is correct. A person has to check that the statement says what we claim. This page is the person's part: about twenty lines of definitions, a handful of theorem statements, and one command to check axioms. You do not need to read any proofs.

What you have to trust

To believe "Lean proves s(32) = 6" you need three things. Everything else (the 30,000-leaf certificate trees, the generators, the Python checkers) is outside the trusted part, because the kernel re-derives it.

  1. The definitions of a unit square, a packing, the container, and s(n). Below, with a reading of each.
  2. The theorem statement, for example theorem s32_eq_6 : minSide 32 = 6, including any hypothesis it takes.
  3. The axioms the proof uses. #print axioms s32_eq_6 should list only Lean's three standard ones: propext, Classical.choice, Quot.sound. No sorryAx (an unfinished proof) and no Lean.ofReduceBool (which would mean native_decide trusted compiled code).

Plus Lean itself and Mathlib, which we take as given. Toolchain: leanprover/lean4:v4.33.1.

The definitions

All in namespace SquarePacking. Points are pairs of reals, ℝ × ℝ; p.1 and p.2 are the x and y coordinates.

Rotated coordinates

noncomputable def coord (c : ℝ × ℝ) (θ : ℝ) (p : ℝ × ℝ) : ℝ × ℝ :=
  ((p.1 - c.1) * Real.cos θ + (p.2 - c.2) * Real.sin θ,
   (-(p.1 - c.1)) * Real.sin θ + (p.2 - c.2) * Real.cos θ)

Basic.lean:28

The coordinates of point p in a frame centred at c and turned by angle θ. In matrix form it is R(−θ)(p − c): shift so c is the origin, then rotate back by θ. noncomputable only means Lean can't run it as a program, because it uses real cosines; it has no effect on proofs.

A square, closed and open

def sq (c : ℝ × ℝ) (θ L : ℝ) : Set (ℝ × ℝ) :=
  {p | |(coord c θ p).1| ≤ L/2 ∧ |(coord c θ p).2| ≤ L/2}

def sqInt (c : ℝ × ℝ) (θ L : ℝ) : Set (ℝ × ℝ) :=
  {p | |(coord c θ p).1| < L/2 ∧ |(coord c θ p).2| < L/2}

Basic.lean:33, 37

sq c θ L is the set of points whose rotated coordinates both lie in [−L/2, L/2]. That is the closed square of side L, centre c, turned by θ. sqInt is the same with strict inequalities: the open square, which is the interior of sq. Every square of side L in the plane is sq c θ L for some c and θ, so nothing is lost by this parametrisation.

The container

def box (t : ℝ) : Set (ℝ × ℝ) := {p | 0 ≤ p.1 ∧ p.1 ≤ t ∧ 0 ≤ p.2 ∧ p.2 ≤ t}

Chord.lean:28

The closed square [0, t] × [0, t].

A packing

def Packs (n : ℕ) (s : ℝ) : Prop :=
  ∃ (ctr : Fin n → ℝ × ℝ) (ang : Fin n → ℝ), (∀ i, sq (ctr i) (ang i) 1 ⊆ box s) ∧
    ∀ i j, i ≠ j → Disjoint (sqInt (ctr i) (ang i) 1) (sqInt (ctr j) (ang j) 1)

S32.lean:34

∃ ctr ang
There are a centre and an angle for each of the n squares. Fin n is the index set {0, …, n−1}.
sq … 1 ⊆ box s
Each closed unit square lies inside the closed container of side s.
Disjoint (sqInt …)
Any two different squares have disjoint interiors. Touching along an edge or at a corner is allowed, overlapping area is not.

This is the standard definition from the literature (Erdős–Graham, Friedman's survey): closed unit squares, any orientation, interiors pairwise disjoint, contained in the closed container.

s(n)

noncomputable def minSide (n : ℕ) : ℝ := sInf {s | Packs n s}

S32.lean:39

The infimum of all sides s for which a packing of n unit squares exists. The infimum is attained: s(n) is a minimum. That is now a Lean theorem, proved by compactness:

theorem isLeast_minSide {n : ℕ} (hn : 1 ≤ n) : IsLeast {s | Packs n s} (minSide n)
theorem minSide_eq_iff_isLeast {n : ℕ} (hn : 1 ≤ n) {k : ℝ} :
    minSide n = k ↔ IsLeast {s | Packs n s} k

Attain.lean:136, 189

So minSide n = k means exactly "n squares fit in side k, and in no smaller side". IsLeast S k is Mathlib's "k is in S and is below every element of S".

Things a careful reader checks

Lean's sInf of an empty or unbounded set is 0.

This convention could make a statement about minSide trivially true. It doesn't apply here: for n ≥ 1 the set is non-empty (a grid always fits) and bounded below by 1, so minSide n is the real infimum.

Natural-number subtraction truncates at 0.

In minSide (k ^ 2 - 3), k is a natural number, and 2 - 3 = 0 in ℕ. The theorem assumes 6 ≤ k, so k² − 3 is the true value.

Closed versus open.

Containment uses the closed square, disjointness uses the open one. If both were closed, squares could not even touch and every bound would shift. If containment used the open square, a square could poke its boundary out of the container. The combination used is the standard one.

Angles are unrestricted reals.

No angle is excluded. The proofs reduce to θ ∈ [0, π/4] by symmetry, but that reduction is proved, not assumed.

The definitions are spread across three files.

coord, sq and sqInt are in Basic.lean, box is in Chord.lean, Packs and minSide are in S32.lean. A single short Spec.lean would make review easier. That is a proposed cleanup, not done yet.

The theorems

A no hypothesis theorem is a complete proof. A conditional theorem has the form "if H then s(n) = k". Lean proves the implication. H is what an external checker (Python or Rust) asserts. If H were false, the theorem would be true but say nothing.

The two hypotheses

def S21CheckerCover : Prop :=
  ∀ (c : ℝ × ℝ) (u : ℝ), c.1 ∈ Set.Icc 0 (5 / 2) → c.2 ∈ Set.Icc 0 (5 / 2) →
    u ∈ Set.Icc 0 (1 / 2) → sq c (2 * Real.arctan u) 1 ⊆ box 5 →
      1 ≤ ∑ e ∈ pentries.filter (fun e => pt e ∈ sq c (2 * Real.arctan u) 1), pw e
        + ∑ e ∈ sentries, sw e * segFrac (sa e) (sb e) (sq c (2 * Real.arctan u) 1)

S21.lean:279

In words: for every unit square inside [0,5]² with centre in the lower-left quarter and angle 2·arctan(u), u ∈ [0, ½] (that is, θ ∈ [0, ~53°], which covers [0, 45°]), the weights of the cover's points inside the square, plus each segment's weight times the fraction of it inside the square, add up to at least 1. This is the "every square catches mass ≥ 1" property of the s(21) cover, restricted to one symmetry class. The cover data (pentries, sentries) is in S21Data.lean.

def Valid7 : Prop :=
  ∀ (c : ℝ × ℝ) (θ : ℝ), sq c θ 1 ⊆ box 7 → 1 ≤ box7Cover.measure (sq c θ 1)

Bentz.lean:65

Every closed unit square inside [0,7]² gets mass at least 1 from the 7×7 cover (segments on 60 lines plus density 1 on an inner square). Lean proves the rest: that this one finite fact gives s(k² − 3) = k for every k ≥ 6. To read Valid7 you also have to trust the definition of box7Cover.measure, because a wrong measure would make the hypothesis mean something else.

Why a cover proves a lower bound

This is the one idea behind every lower bound above, so it helps to see it once. Suppose a measure μ on [0,k]² gives every unit square mass at least 1, and the total mass is less than n. Suppose n squares fit in a side s < k. Scale the packing up by k/s. Each square grows to side k/s > 1, and the concentric unit square inside it is strictly inside the grown square. The n unit cores are therefore pairwise disjoint as closed sets, so their masses add: at least n in total. That exceeds μ's total mass, a contradiction. Lean's version is not_packs_of_measure. The scaling step is what lets a cover with zero slack, where some square catches exactly 1, still prove s(n) ≥ k.

How other projects state it

Every Lean project on this problem defines the same set of admissible sides for n ≥ 1. The differences are in notation and in how a result is phrased. This comparison is from reading the source on 2026-10-01; we did not build the other projects.

Open squares inside an open box, pairwise disjoint, describe the same configurations as our closed-inside-closed with disjoint interiors. Allowing reflections adds nothing, since a reflected square is a rotated square. Both facts are now Lean theorems, below.

A common specification

Spec.lean (namespace UnitSquarePacking, imports only Mathlib) restates the definitions in Mathlib's idiom, as a candidate shared spec for all projects:

def unitSq (c : ℝ × ℝ) (θ : ℝ) : Set (ℝ × ℝ) :=
  (fun p => c + rot θ p) '' (Icc (-1/2) (1/2) ×ˢ Icc (-1/2) (1/2))
def container (s : ℝ) : Set (ℝ × ℝ) := Icc 0 s ×ˢ Icc 0 s
def Packs (n : ℕ) (s : ℝ) : Prop :=
  ∃ (c : Fin n → ℝ × ℝ) (θ : Fin n → ℝ), (∀ i, unitSq (c i) (θ i) ⊆ container s) ∧
    Pairwise fun i j => Disjoint (interior (unitSq (c i) (θ i))) (interior (unitSq (c j) (θ j)))

Here the square is the image of [−½, ½]² under a rotation and a shift, and the open square is Mathlib's interior of it, instead of a separate definition. Two bridges are proved:

  • packs_iff : SquarePacking.Packs n s ↔ UnitSquarePacking.Packs n s, so every result on this page holds in the spec's terms.
  • packs_iff_nonempty_packing : Packs n x ↔ Nonempty (Packing n UnitSquare (Square x)), the bridge to formal-conjectures' open-square, isometry-placed definition. For example, s(13) = 4 is restated in their exact form as s13_fc.

The spec states results in three shapes: exact IsLeast {s | Packs n s} k, lower ∀ s, Packs n s → a ≤ s, upper Packs n b (an explicit packing).
