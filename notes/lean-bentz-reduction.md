## The theorem

```lean
theorem SquarePacking.Bentz.bentz_of_valid7 (h : Valid7) :
    ∀ k : ℕ, 6 ≤ k → minSide (k ^ 2 - 3) = k
```

`#print axioms` → `[propext, Classical.choice, Quot.sound]` (also for `box7Cover_measure`, `famCover_total`,
`mass_shift`).  No `sorry`, no `native_decide`.  `minSide`, `Packs`, `sq`, `box` are the definitions used by
`S13Lower.lean` / `S32.lean`.

**The hypothesis** (`Bentz.lean` §1):

```lean
def Valid7 : Prop :=
  ∀ (c : ℝ × ℝ) (θ : ℝ), sq c θ 1 ⊆ box 7 → 1 ≤ box7Cover.measure (sq c θ 1)
```

`box7Cover` is `search/qx2_data/L4_k02_box7.txt` (sha256 `c0a67509…694b`) verbatim, as a `MixedCover`
(`MixedMeasure.lean`): no points; the 800 segments in file order, `(X0/5, Y0/5)–(X1/5, Y1/5)` with mass `w/10¹²`
spread uniformly by length (`segMeasure`: parametric fraction, FORMAT.md's `|seg ∩ Q|/|seg|`); one polygon, the
intersection of the left half-planes of its 4 directed edges (`convPoly`, = `[9/5, 26/5]²`, proved), mass
`11560000000000/10¹²` spread uniformly by area.  That is FORMAT.md's "what a file asserts" for this file:
every closed unit square in `[0,7]²`, every centre and angle, has mass `≥ 1` — what Lemma Z (`θ = 0`) plus
`qx2_zm.py` run V2 (`θ > 0` on the D4 domain, with the D4 symmetry checked by `Cover.symmetric_d4`) certify
(QUADRANT_EXACT.md §0, §3, §6).  The data is generated by `python3 lean/scripts/gen_bentz_data.py --search
<s12/search>` (asserts the header `mixed 1 / 7 1 / 5 / 10¹² / 0 points / 1 polygon`; deterministic).

## How it is proved

1. **The family for all k** (`famCover k`, §2).  Unit segments of the 1/5-grid, indexed `(o, i, j) ∈ Bool × ℤ × ℤ`.
   A cell `[i/5,(i+1)/5]` / line `j/5` of one coordinate gets a code: its offset `0..9` from the nearer wall if it
   is within `R = 2` of it, `10 + phase` in the band zone `[2, k − 2]` (the closed ends `2`, `k − 2` are phase-0
   band lines), `15` outside `[0,k]`.  A horizontal segment's mass is `famTab[16·code(x-cell) + code(y-line)]`,
   a vertical one's the diagonal image; plus Lebesgue on `[9/5, k − 9/5]²` (polygon, mass = area).  `famTab`
   (70 non-zero entries) is written from `L4_k02_family.txt` (`3f4771d3…0768`): corner module `H y x0 x1 → (5x0,
   5y)`, `V x y0 y1 → (5y0, 5x)`, profile `h y p0 p1 → (10+5p0, 5y)`, `v p y0 y1 → (5y0, 10+5p)`.  This encodes
   corner module at four corners, profile on `[R, k−R]` along four walls, D4 symmetry built in.
2. **`famCover 7` = the box file** (`box7Cover_measure`, equality of measures; §3, §5): kernel checks that every
   file segment is a unit grid segment (either orientation) with positive mass equal to the table's, that no two
   coincide, and that every grid segment of `[0,7]²` with non-zero table mass is in the file.  So the table is
   cross-checked against the box file by the kernel (this is `qx2_family_check.py`'s multiset check, in Lean).
3. **Accounting** (`famCover_total`, §8): total mass `= k² − 4D`, `D = 423621306389/500000000000`, for every
   `k ≥ 4` (sums by code: each edge code twice, cell phases `k − 4` times, line phase 0 `k − 3` times, other
   line phases `k − 4` times; band×band entries are 0).  Segments sum to `7.2·10¹² m + 12451029548888` (`k =
   m + 4`, units 10⁻¹²).  `σ = 0` shows up as the absence of a `k²`-term.
4. **Localisation** (`mass_shift`, §6–§7): for `k ≥ 6` and `sq c θ 1 ⊆ [0,k]²`, pick per axis an integer shift
   `n` (`Good`): `n = 0` if the axis range `[x₀,x₁]` has `x₁ < min(5, k−2)`; `n = k − 7` if `x₀ > max(2, k−5)`;
   otherwise `[x₀,x₁] ⊂ (2, k−2)` and `n = ⌈x₀⌉ − 3` puts it in `(2,5)`.  Only `x₁ − x₀ = w(θ) < 2` is used.  On the
   cells/lines the square can meet, the codes for `k` and for `7` (shifted) agree, and so does membership in the
   Lebesgue square; so `μ_k(Q) = μ₇(Q − n)` exactly (segment by segment, `segFrac` is translation invariant) with
   `Q − n ⊆ [0,7]²`.
5. **End** (§9): `Valid7` ⇒ `μ_k(Q) ≥ 1` for all closed unit `Q ⊆ [0,k]²`; `μ_k([0,k]²) ≤ k² − 4D < k² − 3`;
   `not_packs_of_measure` (dilation) ⇒ no packing in side `< k`; `packs_grid` ⇒ `Packs (k²−3) k`; so
   `minSide = k`.

## Deviation from the paper argument (QUADRANT_EXACT.md §2)

None of substance, and nothing wrong was found; the route is shorter.  The paper goes μ₇ ⇒ μ_Q (quadrant measure,
integer x-shifts in `{x > R}`) ⇒ μ_k via D4 invariance and localisation to `H = [0, k−R)²`.  Here there is no
quadrant measure and no D4 invariance of μ_k: each axis independently gets an integer shift into `[0,7]`, which
covers corners, walls, band interior and the Lebesgue interior uniformly (the paper's case (d), "square inside U has
mass exactly 1", is subsumed: such a square is shifted into `(2,5)²`, where μ₇ is also Lebesgue).  The closed ends
`x = R`, `x = k − R` and the layer are handled by the codes (the conditions are strict inequalities on the closed
range of the square).  k = 6 comes from μ₇ directly (shift by 0 or −1), consistent with §2.3's remark that μ₆
alone would not give μ_Q.  D4 enters only inside `Valid7` (the Python run's reduction to the fundamental domain).

## Generic vs specialised

Specialised to this family's shape: pitch 1/5, `R = w = 2`, Lebesgue from `a = 9/5`, box `k₀ = 7`, codes `0..15`.
Generic: the table (any values; its nonnegativity is automatic, masses are naturals) — a different profile/corner
module with the same shape needs only `gen_bentz_data.py` and new constants in `seg_total`/`famCover_total`.  For
`k² − 4` (`R = w = 3`, box 9) the numbers 10, 5, 25, 2, 9/5 in `cellT`/`lineT`/`Good`/`lebSq` would become
parameters; the proofs are case splits closed by `omega`/`linarith` and should carry over mechanically.
