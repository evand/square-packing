# `Packs n S*` for the exact forms (generated; committed 2026-10-10)

One module per count, `Sqpack.Exact.Packs.N<n>` (with `N<n>/Data.lean` and chunk modules `N<n>/C<i>.lean`), for the 258
exact forms of `search/exact/minpoly/data/` with field degree ≤ 20.  Each proves, kernel-checked with the standard axioms:

    theorem UnitSquarePacking.EC.N<n>.packs : ∃ s : ℝ, peval pS s = 0 ∧ Sa ≤ s ∧ s ≤ Sb ∧ Packs n s

and, for the 62 quadratic sides, `packs_closed : Packs n (a + b * √d)` and `minSide_le_closed : minSide n ≤ a + b * √d`.
Not in the default build: `cd lean && lake build Sqpack.Exact.Packs.N147`.

Generated by `search/exact/lean_batch.py` (`lean_cert.py --split 25`) from the committed
`minpoly/data/n-N.minpoly.json.gz`; n = 129 and 146 use `--chunk 10` (`--split 10`), because 25-square chunks exceed 14 GB.
`SHA256SUMS` covers every `.lean` file here.  Results: `search/exact/lean_batch/results.md`.
Includes exact forms of packings that are no longer the record (kept for the web viewer and as true statements).
